A one-line deadpan excuse from a robot vacuum for missing a spot: "My sensors classified that spot as load-bearing dust. Removing it would void the floor's warranty, collapse the room, and require a second pass. I checked twice." The program writes that line, and nothing else, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
